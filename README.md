Vice Panels — Cover Art Studio is an offline cover-art studio that turns your own photos and a caption into movie-poster GTA-style cover art. Its flagship Key Art layout rings one big hero panel with smaller character and scene panels, each stamped with an editable character name tag (THE DRIVER, THE CAPTAIN, THE GETAWAY…) and cropped face-aware around its focal point. The title treatment is poster lettering: a striped-chrome main line — sunset bands inside the letters, a thick white keyline, a hard shadow — over a glowing neon-script second line, with toggleable poster furniture (a five-star review strip with quote and VOL. 1 tag, a gold starburst "Original Cover Art" seal, a tagline ribbon, and a billing block with barcode). Four grades include Illustrated, which posterizes photos into drawn key art, alongside Neon Sunset, Midnight Vice and Golden Hour. Six built-in samples — two character portraits and four generated Vice City scenes (neon boulevard, speedboat, skyline, boardwalk) — are dealt one per panel so a fresh cover never repeats an image, and your own photos join them from a file picker or drag & drop, read on your machine only, with per-panel click-select, drag repositioning and zoom under cover-fit clamping. Three more layouts (Classic Grid, Vice Slice, Hero Strips) round out the studio. The preview canvas is kept at the exact export resolution and one click exports a PNG at 1080×1080, 1080×1350 or 1920×1080. No build step, no network requests: serve app/ from any static server and it runs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
node serve.ts
```
