Vice Panels is an offline cover-art studio: load your own photos, arrange them across the multi-panel poster layouts, apply a Vice City colour grade, letter your caption in heavy display type, and export a shareable PNG. Three layouts (Classic Grid, Vice Slice diagonal panels, Hero Strips), three grades (Neon Sunset, Midnight Vice, Golden Hour), per-panel drag-to-position and zoom, two editable caption lines set in Anton (SIL Open Font License), and one-click export at 1080 x 1080, 1080 x 1350 and 1920 x 1080. Everything runs locally in the browser — photos never leave the machine, and the app makes no network requests. Two built-in sample photos (made with an image model) let it work the moment it opens.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
node serve.ts
```
